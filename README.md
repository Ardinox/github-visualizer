Git Visualizer is a full-stack analytics platform that converts raw GitHub repository data into an interactive dashboard. It fetches repository information using the GitHub GraphQL API, processes it into meaningful metrics, and presents developers with insights into project activity, contributors, releases, issues, pull requests, and overall repository health.

## ✨ Features

- Repository Overview
- Language Distribution
- Contributor Analytics
- Commit Activity
- Issue & Pull Request Statistics
- Release Timeline
- Repository Health Score
- Analysis History
- Intelligent Caching
